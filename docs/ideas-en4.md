# EN-4: 自分の居場所がずっとそこにあると感じられる価値

[[enabling-values#EN-4|EN-4]] を実現する 5つの「〜できる価値」に対して、それぞれ 5つの具体的アイデアを列挙。

このアイデア群は [[value-proposition|提供価値]] の「格ゲーシーンへの帰属感が高まる」「忙しくても格ゲーシーンがずっとそこにある感じ」を実現します。

**[[value-analysis#EN-4|EN-4のメモ]]より：**
> 受験を終えて、駅で、「ここでも熱い事やってる」。自分がいない間も、好きな世界は動き続けていた。趣味に戻ってきた。口元が緩む。帰れる場所がある。EN-1よりさらに時間感覚が広いもの。継続的にそこに在籍している感というか、自分の世界があることの感じ。

---

## 価値1: 「ここでも熱い事やってる」と確認できる価値

### アイデア案（5つ）

1. **週刊の定期更新**
   - 毎週決まった曜日に必ず更新
   - 「今週も更新されてる」という安心感
   - [[persona|ペルソナ]]が忙しくて見れない週があっても、「あそこに行けばある」という確信

2. **「今週も熱い」というメッセージ**
   - トップページに「今週も〇〇大会で熱い戦いが！」
   - 世界が動き続けている実感を与える
   - 「自分がいない間も盛り上がってた」という発見

3. **アーカイブの蓄積を見せる**
   - 過去の週刊ページが時系列で並ぶ
   - 「ずっと続いている」歴史が見える
   - スクロールすると「こんなに積み重ねがある」と感じる

4. **「界隈は今週も動いてます」サマリー**
   - トップに今週のハイライトを3行で
   - 忙しくて詳細を見れなくても「今週も何かあったんだな」とわかる
   - 継続性を感じさせる短文

5. **更新通知の継続性**
   - 毎週同じ曜日・時間に通知
   - リズムが生まれる
   - 「あ、また今週も来た」という安心感

## 価値2: 格ゲーシーンがずっとそこにあると実感できる価値

### アイデア案（5つ）

1. **「〇週連続更新中」カウンター**
   - トップページに更新週数を表示
   - 「52週連続更新」など継続性の証明
   - 「このサイトはずっとここにある」信頼感

2. **シーンの年表・タイムライン**
   - SF6シーンの主要な出来事を時系列で表示
   - 「このゲームのシーンはこうやって続いてきた」
   - 過去から未来への連続性を可視化

3. **選手の継続的な活動を見せる**
   - 「〇〇選手は3週連続で上位入賞」
   - 選手たちが継続的にプレイしている様子
   - シーンが生きている証拠

4. **「来週の予告」セクション**
   - 来週の注目大会を予告
   - 「来週もある」という未来への期待
   - 終わらない世界の感覚

5. **コミュニティの継続性を伝える**
   - 「SF6シーンは〇〇年目」
   - 格ゲーコミュニティの長い歴史を紹介
   - 自分が参加しているのは一時的なブームではなく、長く続く世界

## 価値3: 自分の居場所だと感じられる価値

### アイデア案（5つ）

1. **「おかえりなさい」メッセージ**
   - 久しぶりに訪れた時に「おかえりなさい」
   - リピーター向けのウェルカムメッセージ
   - 「ここは自分の場所だ」という実感

2. **自分の観戦履歴を記録**
   - 「あなたは〇週分見ています」
   - 「前回訪問: 2週間前」
   - 自分の参加の軌跡が見える

3. **「あなたと同じように観戦している人たち」**
   - 訪問者数や閲覧数を表示
   - 「自分と同じような人がたくさんいる」
   - 孤独じゃない、コミュニティの一員という実感

4. **コメント・反応機能（軽量）**
   - 「いいね」「熱い」などシンプルなリアクション
   - 自分も参加している感覚
   - 観るだけじゃなく、痕跡を残せる

5. **「あなたのお気に入り選手」機能**
   - 好きな選手を登録すると、その選手の情報が集まる
   - 「自分専用」のカスタマイズ
   - 「ここは自分の場所」という所有感

## 価値4: 忙しくても格ゲーシーンに繋がっていられる価値

### アイデア案（5つ）

1. **週刊ダイジェスト（超短縮版）**
   - 1分で読める今週のサマリー
   - 忙しい週でも最低限追いつける
   - 「完全に離れなくて済む」安心感

2. **「3行で今週」**
   - 箇条書き3行で今週の重要事項
   - [[persona|ペルソナ]]は就活・卒論で忙しい
   - 最低限の繋がりを維持

3. **月次サマリー**
   - 「今月の格ゲーシーン」を月末にまとめ
   - 毎週見れなくても月1で振り返れる
   - 「完全に取り残されていない」実感

4. **通知のカスタマイズ**
   - 「週1回だけ通知」「月1回だけ通知」
   - 自分のペースで繋がれる
   - 強制感なく、緩く繋がり続ける

5. **「忙しかった人向け」キャッチアップ**
   - 「2週間ぶりの方へ：この間こんなことがありました」
   - 復帰者向けの親切な導線
   - いつでも戻ってこれる安心感

## 価値5: 「趣味に戻ってきた」感覚を味わえる価値

### アイデア案（5つ）

1. **「最近見てなかった方へ」セクション**
   - 久しぶり訪問者向けのハイライト
   - 「いない間にこんなことがありました」
   - 温かく迎え入れる雰囲気

2. **過去の週をサッと振り返れる**
   - 過去4週分を1ページで概観
   - 「あ、この間こんなことあったんだ」
   - 復帰のハードルを下げる

3. **「変わらない良さ」の演出**
   - デザインやフォーマットは一貫
   - 「あ、変わってない。戻ってきた」感覚
   - 懐かしさと安心感

4. **「お久しぶりです」メッセージ**
   - 前回訪問から時間が空いた人に優しいメッセージ
   - 責めない、歓迎する
   - 「いつでも戻っていいんだ」という安心

5. **「あの頃のStreetLog」アーカイブ**
   - 自分が初めて見た週のページに戻れる
   - 「あの時からここにいたんだ」という感慨
   - 自分とサイトの歴史を振り返る

## まとめ

EN-4「自分の居場所がずっとそこにあると感じられる価値」を実現するための **25個** のアイデアを列挙しました。

### 5つの価値ごとの方向性

1. **「ここでも熱い事やってる」**: 定期更新、継続性のメッセージ、蓄積の可視化
2. **格ゲーシーンがずっとそこにある**: 連続更新カウンター、年表、来週予告で継続性を証明
3. **自分の居場所**: おかえりメッセージ、履歴記録、コミュニティ感、カスタマイズ
4. **忙しくても繋がれる**: 超短縮版、3行サマリー、月次まとめ、柔軟な通知
5. **趣味に戻ってきた**: 復帰者向けハイライト、温かい歓迎、変わらない良さ

### EN-4の特徴

- **時間感覚が最も広い**: リアルタイム（EN-1）より長期的な継続性
- **「ずっとそこにある」実感**: 一時的ではなく、永続的な場所
- **離脱と復帰に優しい**: 忙しくて離れても、戻ってきやすい
- **所属感・帰属感**: 「自分の場所」「帰れる場所」という感覚

### 他のENとの関連

- **EN-1（リアルタイム共有）**: 「今」に対し、EN-4は「ずっと」
- **EN-2（文脈理解）**: 蓄積された情報が文脈を作る
- **EN-3（火がつく）**: 継続的なプレイ意欲の源泉となる居場所

### [[persona|ペルソナ（陸）]]の行動原理

- 就活・卒論で忙しい時期がある → 超短縮版、月次サマリー
- でも完全には離れたくない → 最低限の繋がりを維持
- 趣味に戻ってきた時の安心感 → 温かく迎え入れる設計
- 「自分の場所」という実感 → カスタマイズ、履歴、コミュニティ感

### 設計上の重要ポイント

**継続性の証明**が鍵：
- 毎週の定期更新（リズム）
- 蓄積の可視化（歴史）
- 未来への予告（続く世界）

**離脱と復帰に優しい**設計：
- 責めない、歓迎する
- キャッチアップしやすい
- いつでも戻れる安心感

**「ここは自分の場所」**を感じさせる：
- 履歴、カスタマイズ、痕跡
- コミュニティの一員
- 変わらない良さ
