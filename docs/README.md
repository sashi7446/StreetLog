## 🔑 重要な気づき・原則

1. **過剰解釈を避ける**: 事象カードにある言葉だけを使う
2. **ペルソナは利用状況の人格化**: その人ではなく、その状況を共有する人全員が対象
3. **KA法は厳格**: 必ず「〜価値」で終わる
4. **複数価値にまたがるアイデア**: 「週刊新聞」のように複数のニーズを同時に満たすアイデアが良い
5. **収束と発散を繰り返す**: 時間をかけてアイデアを練る
