# EN-2: 文脈を知って観戦を深く楽しめる価値

EN-2 を実現する 7つの「〜できる価値」に対して、それぞれ 5つの具体的アイデアを列挙。

---

## 価値1: 選手の背景を知って「へぇー」となれる価値

### アイデア案（5つ）

1. **選手プロフィールページ**
   - 使用キャラ、戦績、代表的な実績を簡潔に表示
   - 「全一〇〇」「元〇〇勢」など肩書きを目立たせる
   - Twitterアカウントへのリンク
   - 「この選手の特徴」を2-3行で説明

2. **週刊ページに選手背景を埋め込み**
   - 注目選手として登場する際に、ミニプロフィールを併記
   - 「初めてこの選手を知る人へ」というセクション
   - 長文は避け、箇条書きで端的に

3. **「今週の注目選手」コーナー**
   - 毎週2-3名をピックアップして深掘り
   - なぜ今週注目すべきか、最近の活躍を記載
   - 過去の印象的なエピソードを紹介

4. **選手タグシステム**
   - 「全一〇〇」「伏兵」「復活勢」などタグ付け
   - タグをクリックすると同じタグの選手一覧が見れる
   - ペルソナが流し読みしてもタグで「お、この人すごい人か」と気づける

5. **選手紹介の自動生成テンプレート**
   - Markdownで選手データを管理
   - 使用キャラ、実績、Twitterなど必須項目を統一
   - 更新コストを下げて継続的に追加しやすく

## 価値2: 「あの人か！」と気づける価値

### アイデア案（5つ）

1. **選手名にホバーでプロフィール表示**
   - 選手名にカーソルを乗せるとポップアップ
   - 使用キャラアイコン、最近の実績を一瞬で確認
   - クリックで詳細ページへ

2. **「この選手、以前も登場」マーク**
   - 過去の週刊ページに登場した選手に「既出」バッジ
   - 「前回登場: 第3週」などリンク付き
   - ペルソナが「あ、この人前も見た！」と気づける

3. **選手登場履歴ページ**
   - 選手ごとに「いつ、どの大会で注目されたか」を時系列表示
   - 週刊ページへの逆引きリンク
   - 「この選手の軌跡」が一目でわかる

4. **Twitterアイコン表示**
   - 選手名の横に小さくTwitterアイコン表示
   - Twitterで見かけた人と紐づけやすくする
   - 「あ、TLで見た人だ！」と気づけるきっかけに

5. **使用キャラアイコンを常に表示**
   - 選手名の横に必ず使用キャラのアイコン
   - 「ルーク使いのあの人か！」と視覚的に気づける
   - キャラアイコンで記憶している人にも優しい

## 価値3: 「この対戦カードは熱い！」とすぐわかる価値

### アイデア案（5つ）

1. **注目対戦カードのハイライト**
   - 週刊ページ内で「今週の激アツカード」をピックアップ
   - なぜ熱いのか（因縁、実力伯仲、リベンジマッチなど）を説明
   - 1-2行で端的に、読み飛ばさない程度に

2. **対戦履歴の自動表示**
   - 過去の対戦成績を表示（「A選手 vs B選手: 過去3-2」）
   - 「前回はB選手が勝利」など直近結果を併記
   - データがあれば自動表示、なければ非表示

3. **「因縁マッチ」バッジ**
   - 過去に何度も対戦している組み合わせに「因縁」マーク
   - 地域対決、師弟対決、ライバル関係など手動タグ付け
   - 目立つ色で表示して「これは見逃せない」と感じさせる

4. **ランキング差の表示**
   - 「1位 vs 2位」「全一 vs 新星」など相対的な位置を明示
   - ペルソナは順位を覚えていないので毎回表示
   - 「格上 vs 格下の番狂わせ？」など文脈を添える

5. **コミュニティの期待度表示**
   - Twitter等での言及数を「注目度」として表示（実装は後回しでも概念として）
   - 「みんなが注目している対戦」とわかる指標
   - ペルソナが「これ見とくべきやつか」と判断できる

## 価値4: トーナメント表を見て「乗ってる！」と気づける価値

### アイデア案（5つ）

1. **最近の戦績サマリー**
   - 選手名の横に「直近3大会: 優勝、準優勝、3位」など表示
   - 「今勢いがある」と一目でわかる
   - データは手動更新でも、あるだけで価値がある

2. **「連勝中」「波に乗ってる」バッジ**
   - 最近好成績の選手に視覚的なマーク
   - 「この選手、今調子いいんだ」とペルソナが気づける
   - トーナメント表に埋め込んでもいいし、週刊ページでもOK

3. **トーナメント進行状況の視覚化**
   - start.ggのトーナメント表が読めないペルソナ向け
   - 「Aブロック決勝進出者」「Bブロック注目選手」などピックアップ
   - 「誰が勝ち上がってるか」を文章で説明

4. **「ダークホース」「伏兵」タグ**
   - 予想外の勝ち上がりをしている選手にタグ
   - 番狂わせのストーリーを説明
   - ペルソナは「お、面白い展開だな」と気づける

5. **選手の「今大会の様子」コメント**
   - 「今日は絶好調」「苦戦中だが粘っている」など一言添える
   - 実際の試合を見ていなくても「今の状況」がわかる
   - トーナメント表に文脈を与える

## 価値5: 解説がなくても文脈を持って観戦できる価値

### アイデア案（5つ）

1. **「この試合の見どころ」事前説明**
   - 配信前に「注目ポイント」を箇条書き
   - 「〇〇選手の△△に注目」「キャラ相性は五分」など
   - 解説がいなくても自分で文脈を持てる

2. **選手の最近の調子を一言で**
   - 「絶好調」「復調中」「苦戦気味」など状態を明示
   - ペルソナは詳しく調べないので、端的な情報が助かる
   - 試合前に読むだけで観戦の深みが増す

3. **過去の名勝負リンク**
   - 「この2人の前回対戦はこちら」とYouTubeリンク
   - 時間があれば予習できる、なくても「熱いカードなんだ」と伝わる
   - アーカイブは外部（YouTube等）に任せる

4. **「初見でもわかる」試合前ガイド**
   - 「今日の試合を楽しむための3つのポイント」
   - 長文は避け、箇条書きで3-5個
   - ペルソナは流し読みするので、簡潔に

5. **キャラ相性の簡易説明**
   - 「ルーク vs ケン: 五分〜微有利」など
   - ペルソナはキャラ相性を全て覚えていない
   - 「不利キャラに挑む」など文脈を添えると観戦が面白くなる

## 価値6: 知らない選手を知れる価値

### アイデア案（5つ）

1. **「今週のニューフェイス」コーナー**
   - 新たに注目すべき選手を毎週紹介
   - 「なぜ今注目すべきか」を簡潔に説明
   - ペルソナは自分で探さないので、提示されると助かる

2. **選手発見のきっかけを提示**
   - 「〇〇で好成績」「Twitterで話題」など
   - なぜこの選手がリストに載っているか理由を明示
   - 「知らない人だけど、注目する価値あるんだ」と納得できる

3. **既知選手との関係性を説明**
   - 「〇〇選手のライバル」「同じ地域のトッププレイヤー」
   - 知ってる選手との繋がりで記憶に残りやすい
   - ペルソナの既知情報に紐づけて紹介

4. **使用キャラで選手を探せる機能**
   - 「ルーク使いの注目選手一覧」
   - ペルソナは自分の使用キャラの選手に興味がある
   - キャラ別インデックスがあると発見しやすい

5. **選手一覧ページ**
   - 全選手をキャラ別、地域別、実績別で一覧化
   - ペルソナは能動的に探さないが、「一覧見てみるか」はある
   - 更新しやすいMarkdownベースの管理

## 価値7: 観戦の質が上がる価値

### アイデア案（5つ）

1. **「観戦ガイド」コンテンツ**
   - 「格ゲー観戦がもっと楽しくなる10のポイント」的な記事
   - 初心者〜中級者向けに観戦の視点を提供
   - ペルソナは能動的に学ばないが、目に入れば読む

2. **用語集ページ**
   - 「確反」「暴れ」「リバサ」など格ゲー用語を説明
   - 配信や記事で出てきた用語にリンク
   - ペルソナは全部覚えてないので、都度参照できると助かる

3. **「今週の名場面」解説**
   - 週刊ページで印象的なプレイを振り返り
   - なぜすごいのか、技術的背景を簡単に説明
   - 見た人は「あれそういうことだったのか」と理解が深まる

4. **選手のプレイスタイル説明**
   - 「攻撃的」「読み合い重視」「堅実」など
   - プロフィールに記載して観戦時の見どころを提示
   - ペルソナは「この選手の持ち味はこれか」と意識して見れる

5. **観戦前チェックリスト**
   - 「この試合を見る前に知っておくと良いこと」
   - 選手背景、過去対戦、注目ポイントをまとめて提示
   - 1分で読めるサマリーがあると観戦の質が一気に上がる

## まとめ

EN-2「文脈を知って観戦を深く楽しめる価値」を実現するための **35個** のアイデアを列挙しました。

### 7つの価値ごとの方向性

1. **選手背景**: プロフィール、肩書き、タグで「へぇー」を引き出す
2. **「あの人か！」**: 視覚的要素（アイコン、バッジ）と履歴で既視感を与える
3. **熱いカード**: 対戦履歴、因縁、ランキング差で注目度を明示
4. **乗ってる！**: 戦績サマリー、連勝バッジ、ダークホースタグで勢いを可視化
5. **解説なし観戦**: 事前ガイド、見どころ、キャラ相性で文脈を提供
6. **選手発見**: ニューフェイス紹介、関係性説明、キャラ別索引で出会いを創出
7. **観戦の質**: 用語集、名場面解説、プレイスタイル説明で理解を深める

これらのアイデアは **ペルソナ（陸）の行動原理** に基づいています：
- 能動的に調べるのは苦手 → 情報は自然に目に入るように配置
- 流し見する癖 → 視覚的要素（バッジ、アイコン）で一瞬で伝わるように
- 文脈があると観戦が楽しい → 簡潔な説明を試合前に提示
