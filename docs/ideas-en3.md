# EN-3: ハイレベルな攻防を見て「俺もやりたい」と火がつく価値

[[enabling-values#EN-3|EN-3]] を実現する 5つの「〜できる価値」に対して、それぞれ 5つの具体的アイデアを列挙。

このアイデア群は [[value-proposition|提供価値]] の「注目試合を見つけやすくなる」「俺もやりたいと思える」を実現します。

**[[value-analysis#EN-3|EN-3のメモ]]より：**
> リアルタイム性と関係なく、最上位勢の戦いで感じる"何か"。純粋にハイレベルなプレイを見て魅入ってしまいたい。自分ができないプレイに「うおおお」って興奮したい。あんなプレイしたいと憧れたい。息の詰まるような攻防を見て、俺もやりたいと火がついてうずうずしちゃう。

---

## 価値1: 好きな選手のプレイを見て「超嬉しい」となれる価値

### アイデア案（5つ）

1. **好きな選手の今週の出場情報**
   - トップページで「今週〇〇選手が出場」と目立つ表示
   - ペルソナは全大会を追えないので、好きな選手が出る時だけは絶対見たい
   - 「プロトバナム出るなら絶対見る」という動機に応える

2. **選手別の試合アーカイブリンク集**
   - 選手プロフィールページに過去の名試合YouTubeリンク
   - 「この選手のプレイもっと見たい」に応える
   - アーカイブは外部（YouTube）に任せつつ、入口を提供

3. **好きな選手登録機能**
   - ペルソナが「推し選手」を登録できる
   - その選手が出場する週に通知
   - 能動的に調べるのは苦手だが、好きな選手は見たい

4. **選手の最近のハイライト紹介**
   - 好きな選手の「今週の見どころプレイ」を紹介
   - 「この選手のプレイがかっこいい」という感情に応える
   - 試合を見る前から期待値が上がる

5. **「この選手のここが好き」コメント欄**
   - コミュニティが選手の魅力を語る場所
   - ペルソナは自分で言語化できないが、共感はできる
   - 「わかる！」と思いながら観戦への期待を高める

## 価値2: 「このプレイやばい！」と感動できる価値

### アイデア案（5つ）

1. **「今週のスーパープレイ」コーナー**
   - 週刊ページで印象的なプレイをピックアップ
   - 動画クリップ（YouTube）へのリンク
   - 「このプレイやばい」を週次で共有

2. **プレイの凄さを言語化する解説**
   - 「なぜすごいのか」を簡潔に説明
   - ペルソナは技術的背景がわからないことがある
   - 「確反取ってる」「読み合い制してる」など端的に

3. **「神プレイ」タグ付け**
   - 特に印象的なプレイに「神プレイ」マーク
   - Twitter等で話題になったプレイを拾う
   - ペルソナが「これは見なきゃ」と思えるシグナル

4. **コミュニティの反応を併記**
   - 「Twitterで〇〇件の『やばい』ツイート」
   - 実際のツイート埋め込み（数個）
   - みんなが感動したプレイだと伝わる

5. **プレイ集ページ**
   - 月別、選手別、キャラ別で名プレイを蓄積
   - ペルソナが暇な時に「何か面白いプレイないかな」と見に来る
   - 外部動画へのキュレーション

## 価値3: 圧倒的なプレイを見逃さない価値

### アイデア案（5つ）

1. **「今週の必見試合」マーク**
   - ハイレベルな攻防が期待される試合に「必見」バッジ
   - 「この試合は絶対見た方がいい」と事前に提示
   - ペルソナは全試合見れないので、選別を助ける

2. **「息の詰まる攻防」が期待される対戦の事前告知**
   - 実力伯仲、最上位同士の対戦を強調
   - 「これは見ないと後悔する」というメッセージ
   - リアルタイム性（EN-1）とも関連

3. **試合後の「見どころタイムスタンプ」**
   - アーカイブ（YouTube等）の何分何秒が見どころか
   - リアルタイムで見れなかった人向け
   - 「このシーンだけでも見て」と誘導

4. **レベルの高さを可視化**
   - 「全一同士の対決」「Top8入り常連」など表示
   - ペルソナはランキングを覚えていないので都度提示
   - 「圧倒的なプレイが見られる」期待を与える

5. **「歴史的名勝負」アーカイブ**
   - 過去の伝説級の試合を紹介
   - 新規ペルソナ（2年目）はまだ知らない名試合がある
   - 「これ見たら格ゲー観戦の面白さわかる」的なキュレーション

## 価値4: 針の穴を通すようなプレイに魅入れる価値

### アイデア案（5つ）

1. **プレイの技術的ハイライト解説**
   - 「このタイミングでこの技を出せるのはすごい」
   - 「確反を完璧に取り続けた」など技術面を説明
   - ペルソナは中級者なので、言われれば「なるほど」となる

2. **「職人芸」タグ**
   - 精密なプレイ、読み合いの妙技にタグ付け
   - 「力技」ではなく「技術」で魅せるプレイを強調
   - プレイスタイルの好みに応える

3. **フレーム単位の攻防を紹介**
   - 「1フレームの読み合い」など細かい攻防をピックアップ
   - 動画のスロー再生やキャプチャで解説
   - 「針の穴を通す」感覚を言語化

4. **「このプレイの意図」を解説**
   - なぜこのタイミングでこの行動を選んだか
   - 読み合いの背景を説明
   - ペルソナが「そういうことか！」と理解して魅入る

5. **上級者向け観戦ポイント**
   - 「ここに注目」という視点を提供
   - フレーム、択、読み合いなど中級者が見落としがちなポイント
   - 観戦の質を上げる（EN-2とも関連）

## 価値5: 俺もあんなふうにと憧れられる価値

### アイデア案（5つ）

1. **「このプレイを真似したい」コーナー**
   - 週刊ページで「今週の真似したいプレイ」
   - 「俺もこれできるようになりたい」という憧れを刺激
   - 観戦→プレイ意欲のループ

2. **プレイヤーのモチベーション語録**
   - 選手の「なぜこのゲームをやるのか」を紹介
   - 格ゲー界の名言（「俺は咲きたい」的な）を収集
   - ペルソナが「俺もプレイ頑張ろう」と思える

3. **「見たら絶対やりたくなる試合」リスト**
   - 観戦後にうずうずする試合を厳選
   - 「これ見たら格ゲーやりたくなる」保証付き
   - アーカイブへのリンク集

4. **選手の練習風景・裏話**
   - 「こうやって強くなった」エピソード
   - ペルソナは自分も上手くなりたい気持ちがある
   - 憧れと現実の接続

5. **「観戦→プレイ」の導線設計**
   - 観戦後に「今日のランクマ頑張ろう」と思わせる
   - StreetLogは観戦サイトだが、プレイ意欲を刺激する
   - 「俺もやりたい」を形にする外部リンク（Discord、攻略サイト等）

## まとめ

EN-3「ハイレベルな攻防を見て『俺もやりたい』と火がつく価値」を実現するための **25個** のアイデアを列挙しました。

### 5つの価値ごとの方向性

1. **好きな選手**: 推し選手の出場情報、アーカイブ、登録機能で「超嬉しい」を実現
2. **やばいプレイ**: スーパープレイ紹介、解説、タグ付けで感動を共有
3. **見逃さない**: 必見マーク、事前告知、タイムスタンプで圧倒的プレイへの導線
4. **針の穴**: 技術解説、職人芸タグ、フレーム単位解説で精密なプレイに魅入る
5. **憧れ**: 真似したいプレイ、語録、練習風景で「俺もやりたい」を刺激

### EN-3の特徴

- **リアルタイム性に依存しない**: アーカイブでも成立する価値
- **プレイの質・美学に焦点**: 文脈（EN-2）よりプレイそのものに注目
- **観戦→プレイ意欲の循環**: 見ることで自分もやりたくなる
- **「うおおお」「うずうず」**: 感情の高ぶりと行動欲求を刺激

### 他のENとの関連

- **EN-1（リアルタイム共有）**: 必見試合の事前告知で重なる
- **EN-2（文脈理解）**: 技術解説、観戦ポイントで重なる
- **EN-4（居場所）**: 継続的なプレイ意欲維持で間接的に関連

**ペルソナ（陸）の行動原理**:
- 好きな選手は絶対見たい → 推し選手機能
- 能動的に探さない → 「今週の〇〇」で提示
- 見たら「俺もやりたい」となる → 観戦後のプレイ意欲を刺激
